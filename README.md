# Email Extractor

A simple Python project that extracts email addresses from a text file.

## Files
- `email_extractor.py` – Extracts email addresses from the input file.
- `sample_input.txt` – Contains sample text for testing.

## How to Run
1. Make sure Python is installed.
2. Keep both files in the same folder.
3. Run the following command:

```bash
python email_extractor.py
```

## Purpose
This project is a small practice exercise to learn file handling and regular expressions in Python.
